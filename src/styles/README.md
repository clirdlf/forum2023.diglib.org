# Preserved design styles

`imported/` contains the frozen Elementor/theme/widget CSS required for the migrated design. Files are named by their initial content hash; `src/_data/legacyStyles.json` records each page's ordered list. These are migration artifacts, not generated by the normal build or fetched from WordPress.

`buildStyles()` in `scripts/lib/styles.mjs` creates a shared prefix bundle and a page-specific bundle, preserving the original cascade order. Bundles are named by content hash and written under `.cache/styles/`, then copied into `_site/assets/styles/`. `src/assets/site.css` is the authored override layer. The source styles themselves are not published.

Make normal design changes in `site.css`. If editing an imported file is unavoidable, retain its filename and record the reason here; the public bundle filename still changes automatically with its contents. Existing media and font URLs remain local and stable.
